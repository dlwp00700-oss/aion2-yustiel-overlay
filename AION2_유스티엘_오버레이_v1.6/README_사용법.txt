AION2 유스티엘 주간 콘텐츠 오버레이 v1.6.0
=============================================

[새 기능]
- 상세설정 > 백금공 계산기: 기존 HTML 계산식 통합
- 상세설정 > 업데이트: GitHub 저장소 연결 및 새 버전 설치
- 프로그램을 켠 상태에서 공개 GitHub Release 자동 확인 (첫 확인 약 15초 후, 이후 약 6시간 간격)
- 새 버전을 발견하면 Windows 알림 배너 안내
- GitHub Release 첨부 ZIP의 SHA-256 값을 확인하고 설치
- 업데이트 완료 시 창 없이 다시 실행 / 기존 개인 설정 보존

[실행]
1. ZIP을 완전히 압축 해제합니다.
2. AION2_start.vbs 를 더블클릭합니다 (CMD/PowerShell 창을 띄우지 않음).
3. 게임을 켜면 오버레이가 표시됩니다. 상세설정 버튼을 눌러 새 탭을 확인하세요.
4. 게임 실행 없이 미리 보려면 AION2_preview.vbs 를 실행하세요.
5. 종료: 트레이 아이콘 우클릭 > 프로그램 완전 종료.

[백금공 계산식: 사용자 기존 HTML 수정본 기준]
서로 배타적인 실패/성공/대성공 확률 77%/20%/3%.
- 은공 -> 금공 성공 20%: 금공 1개, 대성공 3%: 백금공 1개
- 금공 -> 백금공 성공 20%: 백금공 1개, 대성공 3%: 백금공 2개
- 은공 하나당 백금공 0.082개, 금공 하나당 백금공 0.260개 기대
- 은공 제작비 150,000키나 / 금공 제작비 200,000키나
- 은공 제작에서 나온 금공을 모두 다음 단계 제작에 사용한다고 가정.
- 기댓값은 실제 획득량을 보장하지 않습니다.

[GitHub 연결]
1. 공개(Public) GitHub 저장소를 만듭니다. 예: 계정명/aion2-yustiel-overlay
2. GitHub 저장소 > Releases > Draft a new release.
3. 태그 v1.6.0, 제목 AION2 Overlay v1.6.0, 아래 배포용 ZIP 파일 첨부.
4. 첨부 파일 이름을 반드시 AION2_Yustiel_Overlay_Update.zip 으로 유지합니다.
5. Release Publish 후 상세설정 > 업데이트 > 계정명/저장소명 입력 후 [주소 저장].
6. v1.6.0에서는 이미 최신이라 표기되고 v1.6.1 이상을 게시하면 업데이트 가능합니다.
7. 새 버전 게시할 때마다 v1.6.1, v1.6.2 등 태그를 올리고 배포 ZIP을 첨부합니다.

[업데이트 주의]
- 새 버전이 있다고 임의로 설치하지 않습니다. 반드시 사용자가 [업데이트 설치] 클릭.
- 연결된 공개 GitHub 저장소가 신뢰할 수 있는 저장소인지 확인하세요.
- SHA-256은 무결성 검사입니다. 악성 소프트웨어에 대한 완전한 안전 보증은 아닙니다.
- 앱이 업데이트 중 종료됐다가 자동 재실행됩니다.
- 업데이트의 대상 파일은 앱 코드와 schedule.csv 등이며 개인 설정은 유지합니다.
- 파일을 다른 폴더로 옮기기보다 처음부터 사용할 고정 폴더에 두는 것이 좋습니다.
- 관리자 권한이 필요한 설치 폴더에는 쓰기 권한 문제로 업데이트가 실패할 수 있습니다.
- 앱 경고/오류 기록: %LOCALAPPDATA%\AION2_Yustiel_Overlay\update_last.txt
- 응용프로그램 오류 기록: %LOCALAPPDATA%\AION2_Yustiel_Overlay\last_error.txt

[기존 설정 유지]
%APPDATA%\AION2_Yustiel_Overlay\settings_ps.json
%APPDATA%\AION2_Yustiel_Overlay\schedule_overrides.csv

[보안/기술]
메모리 접근/패킷 후킹/게임 DLL 인젝션 없이 프로세스 이름만 확인합니다.
PowerShell 5.1 + Windows Forms. PC가 꺼지거나 절전 상태면 알림이 울리지 않습니다.
실제 Windows 실행 테스트는 별도 환경에서 검증해야 합니다.
