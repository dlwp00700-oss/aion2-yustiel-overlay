AION2 유스티엘 오버레이 v1.8.4

[실행]
- 전체 ZIP을 폴더에 압축 해제하고 AION2_start.vbs 더블클릭.
- 작업표시줄 오른쪽 트레이에서 프로그램 실행 여부를 확인할 수 있습니다.
- 게임이 켜지면 오버레이 자동 표시 (설정 가능).
- 게임을 꺼두면 오버레이가 숨겨져도 알림은 백그라운드에서 동작합니다.
- 게임 없이 화면 확인은 AION2_preview.vbs 실행.
- 종료하려면 트레이 메뉴의 '프로그램 완전 종료' 선택.

[카이라]
- 어비스 하층 '감시자 카이라' 매일 01:00·05:00·09:00·13:00·17:00·21:00 (한국 서버 시각).
- 화면에 가장 가까운 카이라 출현 시각 한 줄만 표시합니다.
- 상세설정 > 콘텐츠·시간표에서 6회 각각 ON/OFF 또는 시간 변경 가능.
- 카이라 6회 모두 기존 설정한 사전 알림 및 시작 알림 대상에 포함됩니다.
- 정령왕 아그로는 2026-10-28 패치 기준 09:00/21:00 고정 출현이며 수동 입력이 필요 없습니다.

[알림]
- 상세설정 > 알림·사운드 > '아이온2 종료 후에도 백그라운드 알림' 기본 켜짐.
- 이 설정은 상시 표시 옵션과 분리되어 있습니다.
- 프로그램이 트레이에서 실행 중이어야 하고 Windows가 로그인/활성 상태여야 합니다.
- PC 종료·절전 중에는 알림이 울리지 않으며 절전 해제 후 지난 알림을 소급 재생하지 않습니다.
- 원하는 경우 상세설정 > 프로그램 > Windows 시작 시 프로그램 자동 실행을 켜세요.

[기존 기능 유지]
- 주간 PvP·보스 시간표, 알림음 3종, 알림 시각·볼륨, 투명도, 그룹별 시각, 백금공 계산기,
  정령왕 아그로 고정 일정, GitHub 새 버전 감지 및 오버레이 업데이트 버튼.

[개인 설정 보존]
- Windows 사용자 설정: %APPDATA%\AION2_Yustiel_Overlay\settings_ps.json
- 변경된 개별 시간표: %APPDATA%\AION2_Yustiel_Overlay\schedule_overrides.csv
- 공개 GitHub 저장소에는 위 설정 파일을 올리지 마세요.

[문제 발생 시]
- 오류로그_열기.cmd로 오류 로그를 확인하거나 디버그_실행.cmd로 진단.
- Windows에서 실행하는 실기 검증은 별도로 필요합니다.

[v1.8.4]
- 정령왕 아그로: 매일 09:00 / 21:00 고정 출현 (10월 28일 패치). 과거 수동 타이머/길드 공유 탭 제거.
- 다음 콘텐츠 강조: 다음 이벤트는 짙은 초록색으로 표시; 시작 시각부터 3분간 이전 이벤트와 다음 이벤트 동시 강조.
- 감시자 카이라는 하루 6회, 오버레이에는 가까운 회차 하나만 표시.
- 개인별 알림 끄기/시간 변경은 상세설정 > 콘텐츠 시간표. 기존 사용자 설정 유지.


[v1.8.5 보기 모드]
오버레이 화면의 '전체 일정' / '간단히 보기' 버튼을 누르면 바로 전환됩니다.
간단히 보기에는 다가오는 시간대 2개(동일한 시간의 콘텐츠는 모두), 3분 경과 유예 중인 콘텐츠만 표시됩니다.
전체 일정 보기의 기존 방식은 그대로 유지되며, 보기 모드 선택은 저장됩니다.
화면에 보이지 않는 콘텐츠도 알림 설정이 켜져 있으면 원래대로 알림이 울립니다.
